
# Random Password Generator

## Project Overview
This is a beginner-friendly Python project that generates random passwords.

## Features
- Generates random passwords.
- Allows users to choose password length.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Shuffles characters for random password generation.

## Technologies Used
- Python 3
- Random module
- String module

## How to Run
1. Open the project folder.
2. Open the terminal.
3. Run:

python password_generator.py

4. Enter your desired password length.
