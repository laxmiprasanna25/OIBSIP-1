
# Python Chat Application

## Project Overview
A real-time chat application developed using Python socket programming.

## Features
- Connect multiple users.
- Send and receive messages.
- Real-time communication.
- Display usernames.
- Server and client architecture.

## Technologies Used
- Python
- Socket Programming
- Multithreading

## How to Run

1. Open the project folder.
2. Start the server:

   python server.py

3. Open another terminal and run:

   python client.py

4. Enter a username.
5. Start chatting!

Type exit to leave the chat.
